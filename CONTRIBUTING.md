# Contributing to AgriFlow

Thank you for your interest in contributing! Follow these steps to get started:

1. Fork the repository and create a feature branch using the ticket naming convention (e.g. `feat/S0-01-devcontainer`).
2. Install dependencies and run the project inside the Dev Container.
3. Ensure linting, formatting, and tests pass before committing.
4. Use [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/) for commit messages.
5. Open a Pull Request using the provided template and wait for reviews.

## Development checklist
- [ ] `npm run lint`
- [ ] `npm test`
- [ ] `npm run test:e2e`
- [ ] `npm run build`

Please also review the [Code of Conduct](CODE_OF_CONDUCT.md).
